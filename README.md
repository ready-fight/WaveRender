# WaveRender

WaveRender is a DirectX 12 renderer portfolio project focused on real-world graphics engineering workflows.

## Goals

- DirectX 12 renderer architecture
- Shader Model 6.x HLSL pipeline
- Wave Intrinsic GPU optimization
- SIMD CPU optimization
- PIX on Windows profiling
- GPU/CPU timing instrumentation
- Professional renderer structure suitable for portfolio review

## Build

Requirements:

- Windows 10/11
- Visual Studio 2022 Build Tools
- Windows SDK
- CMake 3.24+
- VSCode with CMake Tools

Configure:

```powershell
cmake --preset windows-msvc-debug
